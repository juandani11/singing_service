#### CU-34: Evaluar afinación y generar puntaje/errores vocales

| Campo                 | Detalle                                                                                                                                                                                                                                                    |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-34: Evaluar afinación y generar puntaje/errores vocales                                                                                                                                                                                                 |
| **Propósito**         | Medir qué tan cerca estuvo el alumno de las notas correctas.                                                                                                                                                                                               |
| **Descripción**       | El sistema compara las curvas de pitch y detecta notas fuera de tono.                                                                                                                                                                                      |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                           |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                           |
| **Precondición**      | Curvas de pitch extraídas (CU-33).                                                                                                                                                                                                                         |
| **Flujo de Suceso**   | **Evaluar afinación**  <br>1. El Worker alinea temporalmente las curvas de alumno y maestro.  <br>2. Calcula la diferencia en semitonos o cents.  <br>3. Genera una penalización por cada desviación notoria.  <br>4. Calcula un puntaje vocal de 0 a 100. |
| **Postcondición**     | Puntaje vocal y lista de errores de afinación generados.                                                                                                                                                                                                   |
| **Excepción**         | **Disonancia total**  <br>1. La diferencia de tono es extrema en toda la canción.  <br>2. Se otorga el puntaje mínimo y se registra como error grave.                                                                                                      |
