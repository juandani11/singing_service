#### CU-33: Extraer curva de pitch (F0) de alumno y referencia

| Campo                 | Detalle                                                                                                                                                                                                                                        |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-33: Extraer curva de pitch (F0) de alumno y referencia                                                                                                                                                                                      |
| **Propósito**         | Obtener la frecuencia fundamental de la voz para evaluar la afinación.                                                                                                                                                                         |
| **Descripción**       | El sistema procesa las pistas de audio y extrae la curva de tono (F0) en el tiempo.                                                                                                                                                            |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                               |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                               |
| **Precondición**      | Pistas de audio disponibles en el intento y en la referencia.                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Extraer Pitch**  <br>1. El Worker aísla la pista de audio del video.  <br>2. Filtra el ruido de fondo.  <br>3. Aplica un algoritmo de extracción de pitch (ej. YIN, CREPE).  <br>4. Genera una serie temporal de frecuencias (Hz) por frame. |
| **Postcondición**     | Curvas de pitch (F0) del alumno y del maestro extraídas.                                                                                                                                                                                       |
| **Excepción**         | **Audio silencioso o ininteligible**  <br>1. El volumen es muy bajo o hay mucho ruido.  <br>2. El Worker marca el análisis vocal como "No evaluable".                                                                                          |
