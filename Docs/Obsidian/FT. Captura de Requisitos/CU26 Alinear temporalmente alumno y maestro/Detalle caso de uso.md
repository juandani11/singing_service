#### CU-26: Alinear temporalmente alumno y maestro

| Campo                 | Detalle                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-26: Alinear temporalmente alumno y maestro                                                                                                                                                                                                                              |
| **Propósito**         | Sincronizar el ritmo del video del alumno con el del maestro.                                                                                                                                                                                                              |
| **Descripción**       | El sistema ajusta los tiempos (framerate) para comparar frame a frame la ejecución.                                                                                                                                                                                        |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                           |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                           |
| **Precondición**      | Videos normalizados (CU-25).                                                                                                                                                                                                                                               |
| **Flujo de Suceso**   | **Alinear secuencias**  <br>1. El Worker detecta puntos de anclaje (inicio del movimiento, beats de la música).  <br>2. Calcula la diferencia de tiempo (desfase).  <br>3. Aplica interpolación o _Dynamic Time Warping_ (DTW) para sincronizar ambos flujos de landmarks. |
| **Postcondición**     | Secuencias temporales alineadas y listas para cálculo de diferencias.                                                                                                                                                                                                      |
| **Excepción**         | **Desfase extremo**  <br>1. La diferencia de tiempo es mayor al límite permitido.  <br>2. Se notifica que el alumno no siguió el ritmo base.                                                                                                                               |
