#### CU-44: Visualizar dashboard de alumnos, intentos, estados y resultados

| Campo                 | Detalle                                                                                                                                                                                                                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-44: Visualizar dashboard de alumnos, intentos, estados y resultados                                                                                                                                                                                                                    |
| **Propósito**         | Dar al instructor una vista global del desempeño de sus alumnos.                                                                                                                                                                                                                          |
| **Descripción**       | El instructor accede a un panel con métricas y listados de sus alumnos.                                                                                                                                                                                                                   |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                                |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                                |
| **Precondición**      | Tener alumnos vinculados y rutinas asignadas.                                                                                                                                                                                                                                             |
| **Flujo de Suceso**   | **Ver dashboard**  <br>1. El instructor inicia sesión y va al "Dashboard".  <br>2. La app solicita los datos consolidados.  <br>3. El sistema agrupa los intentos por alumno y estado.  <br>4. La app muestra tablas y gráficos con los puntajes promedio, intentos pendientes y alertas. |
| **Postcondición**     | El instructor tiene una visión general del progreso de la clase.                                                                                                                                                                                                                          |
| **Excepción**         | **Sin actividad**  <br>1. Los alumnos no han subido intentos.  <br>2. Se muestra un mensaje para que el instructor envíe recordatorios.                                                                                                                                                   |
