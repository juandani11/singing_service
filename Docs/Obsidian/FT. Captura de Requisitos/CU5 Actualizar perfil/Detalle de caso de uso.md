#### CU-05: Actualizar perfil

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-05: Actualizar perfil                                                                                                                                                                                                                                                                                                                                                   |
| **Propósito**         | Permitir al usuario modificar su información personal.                                                                                                                                                                                                                                                                                                                     |
| **Descripción**       | El usuario edita campos como nombre, avatar y datos básicos, y guarda los cambios.                                                                                                                                                                                                                                                                                         |
| **Actores**           | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                         |
| **Actores Iniciador** | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                         |
| **Precondición**      | El usuario debe tener una sesión activa y estar en la vista de perfil.                                                                                                                                                                                                                                                                                                     |
| **Flujo de Suceso**   | **Actualizar perfil**  <br>1. El usuario selecciona "Editar Perfil".  <br>2. Modifica los campos deseados (nombre, avatar, etc.).  <br>3. El usuario presiona "Guardar".  <br>4. La aplicación valida el formato de los datos.  <br>5. La aplicación envía los cambios al servidor.  <br>6. El sistema actualiza la base de datos.  <br>7. Se muestra un mensaje de éxito. |
| **Postcondición**     | Los datos del perfil son actualizados correctamente.                                                                                                                                                                                                                                                                                                                       |
| **Excepción**         | **Formato inválido**  <br>1. Los datos ingresados no cumplen las validaciones.  <br>2. La aplicación resalta los errores en el formulario.  <br>3. El usuario debe corregir y volver a intentar.                                                                                                                                                                           |
