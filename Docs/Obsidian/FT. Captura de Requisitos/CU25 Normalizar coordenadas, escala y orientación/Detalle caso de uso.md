#### CU-25: Normalizar coordenadas, escala y orientación

| Campo                 | Detalle                                                                                                                                                                                                                                                                                               |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-25: Normalizar coordenadas, escala y orientación                                                                                                                                                                                                                                                   |
| **Propósito**         | Eliminar sesgos de distancia, tamaño o perspectiva de la cámara.                                                                                                                                                                                                                                      |
| **Descripción**       | El sistema ajusta las coordenadas extraídas a un espacio común estándar.                                                                                                                                                                                                                              |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                                      |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                                      |
| **Precondición**      | Haber extraído los landmarks (CU-24).                                                                                                                                                                                                                                                                 |
| **Flujo de Suceso**   | **Normalizar datos**  <br>1. El Worker calcula el centro de masa o cadera del sujeto.  <br>2. Traslada las coordenadas a un origen (0,0).  <br>3. Escala las distancias relativas basándose en la longitud de los huesos.  <br>4. Ajusta la rotación para alinear los hombros/cadera horizontalmente. |
| **Postcondición**     | Landmarks normalizados listos para comparación.                                                                                                                                                                                                                                                       |
| **Excepción**         | **División por cero**  <br>1. Falla el cálculo de escala por datos corruptos.  <br>2. El Worker descarta el frame específico y continúa.                                                                                                                                                              |
