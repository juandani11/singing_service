#### CU-30: Calcular puntaje por segmento (brazos, torso, cadera y piernas)

| Campo                 | Detalle                                                                                                                                                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-30: Calcular puntaje por segmento                                                                                                                                                                                                                                      |
| **Propósito**         | Evaluar de forma aislada el desempeño de cada parte del cuerpo.                                                                                                                                                                                                           |
| **Descripción**       | Se promedia la precisión de las articulaciones agrupadas por zonas corporales.                                                                                                                                                                                            |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                          |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                          |
| **Precondición**      | Microerrores registrados (CU-29).                                                                                                                                                                                                                                         |
| **Flujo de Suceso**   | **Calcular puntajes parciales**  <br>1. El Worker agrupa las diferencias por segmento (brazos, torso, cadera, piernas).  <br>2. Aplica una fórmula de penalización basada en la cantidad y magnitud de los errores.  <br>3. Genera un puntaje de 0 a 100 para cada grupo. |
| **Postcondición**     | 4 puntajes parciales calculados.                                                                                                                                                                                                                                          |
| **Excepción**         | **Segmento no visible**  <br>1. Las piernas estaban fuera de cuadro.  <br>2. El Worker asigna un puntaje nulo o neutral a ese segmento.                                                                                                                                   |
