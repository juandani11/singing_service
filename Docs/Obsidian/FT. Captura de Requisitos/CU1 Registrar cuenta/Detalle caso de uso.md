#### CU-01: Registrar cuenta

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-01: Registrar cuenta                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Propósito**         | Permitir a un nuevo usuario ingresar a la plataforma registrando sus datos básicos.                                                                                                                                                                                                                                                                                                                                              |
| **Descripción**       | El usuario selecciona su rol (Alumno o Instructor) y proporciona sus datos para crear una cuenta.                                                                                                                                                                                                                                                                                                                                |
| **Actores**           | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Actores Iniciador** | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Precondición**      | El usuario no debe estar registrado en la plataforma.                                                                                                                                                                                                                                                                                                                                                                            |
| **Flujo de Suceso**   | **Registro exitoso**  <br>1. El usuario accede a la pantalla de registro.  <br>2. Selecciona su rol (Alumno o Instructor).  <br>3. Ingresa nombre, correo electrónico y contraseña.  <br>4. La aplicación valida el formato de los datos.  <br>5. La aplicación verifica que el correo no exista.  <br>6. La aplicación crea la cuenta y guarda en la base de datos.  <br>7. El sistema redirige al usuario al inicio de sesión. |
| **Postcondición**     | Cuenta de usuario creada exitosamente en el sistema.                                                                                                                                                                                                                                                                                                                                                                             |
| **Excepción**         | **Correo ya registrado**  <br>1. La aplicación detecta que el correo ya existe.  <br>2. Muestra un mensaje de error al usuario.  <br>3. El usuario puede intentar con otro correo.                                                                                                                                                                                                                                               |
