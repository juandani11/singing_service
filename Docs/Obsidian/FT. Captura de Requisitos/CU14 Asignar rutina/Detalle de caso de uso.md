#### CU-14: Asignar rutina

| Campo                 | Detalle                                                                                                                                                                                                                                                                                            |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-14: Asignar rutina                                                                                                                                                                                                                                                                              |
| **Propósito**         | Distribuir una rutina maestra a los alumnos vinculados.                                                                                                                                                                                                                                            |
| **Descripción**       | El instructor selecciona una rutina y los alumnos a los que desea asignarla.                                                                                                                                                                                                                       |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                                         |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                                         |
| **Precondición**      | Tener rutinas creadas y alumnos vinculados.                                                                                                                                                                                                                                                        |
| **Flujo de Suceso**   | **Asignar rutina**  <br>1. El instructor selecciona "Asignar" en una rutina.  <br>2. El sistema muestra la lista de alumnos vinculados.  <br>3. El instructor selecciona uno o varios alumnos.  <br>4. Confirma la asignación.  <br>5. El sistema registra la asignación y notifica a los alumnos. |
| **Postcondición**     | La rutina aparece en el catálogo del alumno.                                                                                                                                                                                                                                                       |
| **Excepción**         | **Sin alumnos vinculados**  <br>1. No hay alumnos disponibles.  <br>2. El sistema muestra un mensaje para invitar alumnos primero.                                                                                                                                                                 |
