#### CU-16: Ver detalle de rutina (instrucciones, dificultad, duración y video maestro)

| Campo                 | Detalle                                                                                                                                                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-16: Ver detalle de rutina                                                                                                                                                                                                                |
| **Propósito**         | Proporcionar al alumno toda la información necesaria para realizar la práctica.                                                                                                                                                             |
| **Descripción**       | El alumno ingresa a una rutina asignada y ve los detalles y el video.                                                                                                                                                                       |
| **Actores**           | Alumno                                                                                                                                                                                                                                      |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                      |
| **Precondición**      | Tener al menos una rutina asignada.                                                                                                                                                                                                         |
| **Flujo de Suceso**   | **Ver detalle**  <br>1. El alumno selecciona una rutina del listado.  <br>2. El sistema recupera los datos de la rutina.  <br>3. Se muestran las instrucciones, dificultad, duración.  <br>4. Se habilita el reproductor del video maestro. |
| **Postcondición**     | El alumno conoce los detalles de la rutina.                                                                                                                                                                                                 |
| **Excepción**         | **Rutina eliminada**  <br>1. El instructor eliminó la rutina.  <br>2. El sistema muestra un mensaje de no disponible.                                                                                                                       |
