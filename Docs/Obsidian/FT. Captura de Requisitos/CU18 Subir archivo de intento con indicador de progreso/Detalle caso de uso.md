#### CU-18: Subir archivo de intento con indicador de progreso

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                 |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-18: Subir archivo de intento con indicador de progreso                                                                                                                                                                                                                                                                               |
| **Propósito**         | Enviar el archivo de video/audio al servidor para su análisis.                                                                                                                                                                                                                                                                          |
| **Descripción**       | El alumno confirma la subida del intento, el sistema valida y muestra el progreso.                                                                                                                                                                                                                                                      |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                                                                                  |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                                                                                  |
| **Precondición**      | Haber grabado o seleccionado un archivo de intento.                                                                                                                                                                                                                                                                                     |
| **Flujo de Suceso**   | **Subir intento**  <br>1. El alumno presiona "Subir Intento".  <br>2. El sistema valida el peso y formato del archivo.  <br>3. Se inicia la subida y se muestra una barra de progreso.  <br>4. Al completarse, el sistema registra el intento y asigna un estado "Pendiente".  <br>5. El sistema dispara el análisis asíncrono (CU-21). |
| **Postcondición**     | El intento se almacena en el servidor y entra a la cola de procesamiento.                                                                                                                                                                                                                                                               |
| **Excepción**         | **Falla de red**  <br>1. Se interrumpe la conexión.  <br>2. El sistema pausa la subida y muestra un error.  <br>3. Se ofrece la opción de reintentar (CU-20).                                                                                                                                                                           |
