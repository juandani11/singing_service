#### CU-17: Grabar video y audio

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Caso de Uso**       | CU-17: Grabar video y audio                                                                                                                                                                                                                                                                                  |
| **Propósito**         | Capturar la ejecución del alumno para su posterior análisis.                                                                                                                                                                                                                                                 |
| **Descripción**       | El alumno utiliza la cámara y micrófono de su dispositivo para grabar su intento.                                                                                                                                                                                                                            |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                                                       |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                                                       |
| **Precondición**      | Estar en la vista de detalle de una rutina asignada y otorgar permisos de cámara/micrófono.                                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Grabar intento**  <br>1. El alumno presiona "Grabar Intento".  <br>2. La app solicita permisos de hardware.  <br>3. Se abre la interfaz de cámara.  <br>4. El alumno presiona "Grabar" y realiza la rutina.  <br>5. El alumno presiona "Detener".  <br>6. La app previsualiza el video y audio capturados. |
| **Postcondición**     | El intento queda grabado temporalmente en el dispositivo.                                                                                                                                                                                                                                                    |
| **Excepción**         | **Permisos denegados**  <br>1. El usuario no otorga permisos.  <br>2. La app muestra un mensaje explicativo.  <br>3. No se permite grabar.                                                                                                                                                                   |
