#### CU-06: Vincular alumno mediante invitación

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                                                |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-06: Vincular alumno mediante  invitación                                                                                                                                                                                                                                                                                                                            |
| **Propósito**         | Crear un vínculo entre un instructor y un alumno para la asignación de rutinas.                                                                                                                                                                                                                                                                                        |
| **Descripción**       | El instructor genera un código o invitación y el alumno lo ingresa para asociarse.                                                                                                                                                                                                                                                                                     |
| **Actores**           | Instructor, Alumno                                                                                                                                                                                                                                                                                                                                                     |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                                                                                                             |
| **Precondición**      | Ambos usuarios deben estar registrados en la plataforma.                                                                                                                                                                                                                                                                                                               |
| **Flujo de Suceso**   | **Vincular alumno**  <br>1. El instructor genera un código de invitación único.  <br>2. El sistema almacena y muestra el código.  <br>3. El instructor comparte el código con el alumno.  <br>4. El alumno ingresa el código en su plataforma.  <br>5. El sistema valida el código y crea el vínculo.  <br>6. Se notifica al instructor que el alumno se ha vinculado. |
| **Postcondición**     | El alumno queda asociado al instructor.                                                                                                                                                                                                                                                                                                                                |
| **Excepción**         | **Código inválido**  <br>1. El alumno ingresa un código incorrecto o expirado.  <br>2. El sistema muestra un mensaje de error.  <br>3. El alumno puede solicitar un nuevo código.                                                                                                                                                                                      |
