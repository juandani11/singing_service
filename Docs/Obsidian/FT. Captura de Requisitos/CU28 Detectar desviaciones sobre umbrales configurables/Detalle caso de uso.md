#### CU-28: Detectar desviaciones sobre umbrales configurables

| Campo                 | Detalle                                                                                                                                                                                                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-28: Detectar desviaciones sobre umbrales configurables                                                                                                                                                                    |
| **Propósito**         | Identificar los momentos exactos donde el alumno se equivocó.                                                                                                                                                                |
| **Descripción**       | El sistema evalúa las diferencias calculadas contra un margen de tolerancia.                                                                                                                                                 |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                             |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                             |
| **Precondición**      | Diferencias calculadas (CU-27).                                                                                                                                                                                              |
| **Flujo de Suceso**   | **Detectar desviaciones**  <br>1. El Worker carga los umbrales (ej. 15 grados de diferencia permitidos).  <br>2. Recorre la matriz de diferencias.  <br>3. Si una diferencia supera el umbral, la marca como una desviación. |
| **Postcondición**     | Lista de desviaciones detectadas con sus valores.                                                                                                                                                                            |
| **Excepción**         | **Umbrales no configurados**  <br>1. No hay umbrales en base de datos.  <br>2. El Worker usa valores por defecto del sistema.                                                                                                |
