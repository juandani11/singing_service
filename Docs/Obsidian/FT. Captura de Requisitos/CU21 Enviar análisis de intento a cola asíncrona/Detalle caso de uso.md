#### CU-21: Enviar análisis de intento a cola asíncrona

| Campo                 | Detalle                                                                                                                                                                                                                                                                                       |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-21: Enviar análisis de intento a cola asíncrona                                                                                                                                                                                                                                            |
| **Propósito**         | Desacoplar la recepción del video del procesamiento pesado de análisis.                                                                                                                                                                                                                       |
| **Descripción**       | El sistema encola un mensaje con la ubicación del video para que un Worker lo procese.                                                                                                                                                                                                        |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                              |
| **Actores Iniciador** | Sistema                                                                                                                                                                                                                                                                                       |
| **Precondición**      | La subida del intento (CU-18) se ha completado exitosamente.                                                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Enviar a cola**  <br>1. El sistema recibe la notificación de subida exitosa.  <br>2. Genera un mensaje con el ID del intento y URLs de archivos.  <br>3. Publica el mensaje en la cola de mensajería (RabbitMQ/SQS).  <br>4. El Worker toma el mensaje de la cola para iniciar el análisis. |
| **Postcondición**     | El mensaje está en la cola y el Worker inicia el procesamiento.                                                                                                                                                                                                                               |
| **Excepción**         | **Cola caída**  <br>1. El servicio de colas no está disponible.  <br>2. El sistema reintenta la publicación o guarda en una cola de errores (Dead Letter Queue).                                                                                                                              |
|                       |                                                                                                                                                                                                                                                                                               |
