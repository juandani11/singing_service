#### CU-11: Eliminar rutina maestra

| Campo                 | Detalle                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-11: Eliminar rutina maestra                                                                                                                                                                                                                                             |
| **Propósito**         | Remover una rutina que ya no es necesaria del catálogo.                                                                                                                                                                                                                    |
| **Descripción**       | El instructor solicita eliminar una rutina y el sistema pide confirmación.                                                                                                                                                                                                 |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                 |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                 |
| **Precondición**      | Ser el dueño de la rutina y tener sesión activa.                                                                                                                                                                                                                           |
| **Flujo de Suceso**   | **Eliminar rutina**  <br>1. El instructor presiona "Eliminar" en el detalle.  <br>2. El sistema muestra un diálogo de confirmación.  <br>3. El instructor confirma.  <br>4. El sistema elimina o desactiva la rutina en la base de datos.  <br>5. Se actualiza el listado. |
| **Postcondición**     | La rutina ya no está disponible.                                                                                                                                                                                                                                           |
| **Excepción**         | **Cancelación**  <br>1. El instructor cancela la eliminación.  <br>2. El sistema cierra el diálogo sin afectar la rutina.                                                                                                                                                  |
