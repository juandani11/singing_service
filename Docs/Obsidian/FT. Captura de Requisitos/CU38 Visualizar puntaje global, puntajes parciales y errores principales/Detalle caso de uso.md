#### CU-38: Visualizar puntaje global, puntajes parciales y errores principales

| Campo                 | Detalle                                                                                                                                                                                                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-38: Visualizar puntaje global, parciales y errores principales                                                                                                                                                                                                                |
| **Propósito**         | Mostrar al alumno un resumen visual de su rendimiento.                                                                                                                                                                                                                           |
| **Descripción**       | El alumno ingresa al detalle del intento y ve gráficos y notas.                                                                                                                                                                                                                  |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                           |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                           |
| **Precondición**      | Intento en estado "Completado".                                                                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Visualizar resultados**  <br>1. El alumno selecciona un intento finalizado.  <br>2. La app descarga los datos de la base de datos.  <br>3. Muestra el puntaje global y los parciales (brazos, piernas, canto).  <br>4. Lista los errores principales con sus marcas de tiempo. |
| **Postcondición**     | El alumno comprende su desempeño general.                                                                                                                                                                                                                                        |
| **Excepción**         | **Datos no disponibles**  <br>1. Error de red.  <br>2. La app muestra una vista de error con opción de reintentar.                                                                                                                                                               |
