#### CU-13: Reproducir video de referencia de rutina

| Campo                 | Detalle                                                                                                                                                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-13: Reproducir video de referencia de rutina                                                                                                                                                                               |
| **Propósito**         | Visualizar el video maestro para comprender la rutina.                                                                                                                                                                        |
| **Descripción**       | El usuario reproduce el video desde el detalle de la rutina.                                                                                                                                                                  |
| **Actores**           | Instructor, Alumno                                                                                                                                                                                                            |
| **Actores Iniciador** | Instructor, Alumno                                                                                                                                                                                                            |
| **Precondición**      | La rutina debe tener un video de referencia asignado.                                                                                                                                                                         |
| **Flujo de Suceso**   | **Reproducir video**  <br>1. El usuario entra al detalle de la rutina.  <br>2. Presiona el botón de reproducción.  <br>3. El sistema carga el reproductor de video.  <br>4. Se inicia la reproducción con controles estándar. |
| **Postcondición**     | El usuario visualiza el video.                                                                                                                                                                                                |
| **Excepción**         | **Error de carga**  <br>1. El video no carga por problemas de red.  <br>2. El sistema muestra un mensaje de error de conexión.  <br>3. El usuario puede reintentar.                                                           |
