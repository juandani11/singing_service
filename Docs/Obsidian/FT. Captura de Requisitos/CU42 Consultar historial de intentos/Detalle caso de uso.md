#### CU-42: Consultar historial de intentos por rutina y fecha

| Campo                 | Detalle                                                                                                                                                                                                                                        |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-42: Consultar historial de intentos por rutina y fecha                                                                                                                                                                                      |
| **Propósito**         | Permitir al alumno revisar sus prácticas anteriores.                                                                                                                                                                                           |
| **Descripción**       | La app muestra una lista cronológica de los intentos realizados.                                                                                                                                                                               |
| **Actores**           | Alumno                                                                                                                                                                                                                                         |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                         |
| **Precondición**      | Haber realizado al menos un intento.                                                                                                                                                                                                           |
| **Flujo de Suceso**   | **Consultar historial**  <br>1. El alumno accede a "Mi Historial".  <br>2. La app solicita los intentos al servidor.  <br>3. El sistema filtra por rutina y fecha.  <br>4. La app muestra las tarjetas de los intentos con su puntaje y fecha. |
| **Postcondición**     | El alumno visualiza sus intentos pasados.                                                                                                                                                                                                      |
| **Excepción**         | **Historial vacío**  <br>1. No hay intentos registrados.  <br>2. Se muestra un mensaje motivacional para empezar a practicar.                                                                                                                  |
