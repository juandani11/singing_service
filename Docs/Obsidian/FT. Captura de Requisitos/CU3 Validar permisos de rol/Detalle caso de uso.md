#### CU-03: Validar permisos de rol 

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Caso de Uso**       | CU-03: Validar permisos de rol                                                                                                                                                                                                                                                                                                                   |
| **Propósito**         | Asegurar que solo los usuarios autorizados accedan a rutas o endpoints específicos.                                                                                                                                                                                                                                                              |
| **Descripción**       | El sistema intercepta las peticiones y verifica el token y rol del usuario antes de conceder acceso.                                                                                                                                                                                                                                             |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                                                                                 |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                                                                                 |
| **Precondición**      | El usuario debe haber iniciado sesión y contar con un token JWT.                                                                                                                                                                                                                                                                                 |
| **Flujo de Suceso**   | **Validación correcta**  <br>1. El usuario intenta acceder a un recurso protegido.  <br>2. El sistema intercepta la petición y extrae el token.  <br>3. El sistema decodifica el token y verifica su validez.  <br>4. El sistema comprueba que el rol del usuario tenga los permisos necesarios. <br>5. El sistema concede el acceso al recurso. |
| **Postcondición**     | El recurso es devuelto al usuario autorizado.                                                                                                                                                                                                                                                                                                    |
| **Excepción**         | **Acceso denegado**  <br>1. El token es inválido, ha expirado o el rol no tiene permisos.  <br>2. El sistema retorna un error HTTP 401 (No autorizado) o 403 (Prohibido).  <br>3. Se deniega el acceso al recurso.                                                                                                                               |
