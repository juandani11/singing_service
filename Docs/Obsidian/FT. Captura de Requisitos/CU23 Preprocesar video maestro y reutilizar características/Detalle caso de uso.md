#### CU-23: Preprocesar video maestro y reutilizar características

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-23: Preprocesar video maestro y reutilizar características                                                                                                                                                                                                                                                                 |
| **Propósito**         | Optimizar el análisis extrayendo características del video maestro una sola vez.                                                                                                                                                                                                                                              |
| **Descripción**       | El Worker extrae poses o características del video maestro y las guarda en caché para comparaciones futuras.                                                                                                                                                                                                                  |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                                                              |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                                                              |
| **Precondición**      | El video maestro (referencia) no ha sido preprocesado previamente.                                                                                                                                                                                                                                                            |
| **Flujo de Suceso**   | **Preprocesar maestro**  <br>1. El Worker detecta un nuevo video maestro.  <br>2. Ejecuta la extracción de landmarks/pose.  <br>3. Normaliza las coordenadas espaciales y temporales.  <br>4. Guarda estas características en la base de datos o almacenamiento de caché.  <br>5. Marca el video maestro como "Preprocesado". |
| **Postcondición**     | Las características del maestro están listas para futuros análisis.                                                                                                                                                                                                                                                           |
| **Excepción**         | **Video maestro corrupto**  <br>1. El Worker no puede extraer los frames.  <br>2. Marca el preprocesamiento como fallido.  <br>3. Notifica al instructor para que suba un nuevo video.                                                                                                                                        |
