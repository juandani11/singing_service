#### CU-47: Notificar finalización del procesamiento al alumno

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                            |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-47: Notificar finalización del procesamiento al alumno                                                                                                                                                                                                                                                                          |
| **Propósito**         | Informar al alumno en tiempo real que su análisis ya está listo para ser visto.                                                                                                                                                                                                                                                    |
| **Descripción**       | El sistema envía una notificación push o mensaje en la app al completarse el intento.                                                                                                                                                                                                                                              |
| **Actores**           | Sistema / Worker, Alumno                                                                                                                                                                                                                                                                                                           |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                                                                   |
| **Precondición**      | El intento acaba de cambiar a estado "Completado" o "Fallido" (CU-22).                                                                                                                                                                                                                                                             |
| **Flujo de Suceso**   | **Enviar notificación**  <br>1. El Worker detecta el cambio de estado a "Completado".  <br>2. Invoca al servicio de notificaciones.  <br>3. Se envía una push notification al dispositivo del alumno.  <br>4. El alumno recibe la alerta "Tu análisis está listo".  <br>5. Al tocar la alerta, la app abre el detalle del intento. |
| **Postcondición**     | El alumno está informado del resultado de su intento.                                                                                                                                                                                                                                                                              |
| **Excepción**         | **Notificación no entregada**  <br>1. El alumno tiene la app cerrada o sin conexión.  <br>2. La notificación se guarda en la bandeja de entrada interna de la app para ser leída luego.                                                                                                                                            |
