#### CU-22: Actualizar estado del intento

| Campo                 | Detalle                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-22: Actualizar estado del intento (pendiente, procesando, completado, fallido)                                                                                                                                                                                          |
| **Propósito**         | Reflejar el avance del pipeline de análisis en la base de datos.                                                                                                                                                                                                           |
| **Descripción**       | El Worker actualiza el estado del intento a medida que avanza el análisis.                                                                                                                                                                                                 |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                           |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                           |
| **Precondición**      | El intento debe existir y estar en la cola o en procesamiento.                                                                                                                                                                                                             |
| **Flujo de Suceso**   | **Actualizar estado**  <br>1. El Worker inicia la tarea y actualiza a "Procesando".  <br>2. Al finalizar exitosamente, actualiza a "Completado".  <br>3. Si ocurre un error irrecuperable, actualiza a "Fallido".  <br>4. Guarda la fecha y hora de cada cambio de estado. |
| **Postcondición**     | El estado del intento está actualizado y visible para el alumno.                                                                                                                                                                                                           |
| **Excepción**         | **Error en base de datos**  <br>1. No se puede actualizar el estado.  <br>2. El Worker registra el error en los logs y reintenta.                                                                                                                                          |
