#### CU-29: Registrar microerrores con timestamp

| Campo                 | Detalle                                                                                                                                                                                                                                                                 |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-29: Registrar microerrores con timestamp                                                                                                                                                                                                                             |
| **Propósito**         | Crear un mapa de errores navegable en la línea de tiempo del video.                                                                                                                                                                                                     |
| **Descripción**       | Las desviaciones detectadas se agrupan y se guardan con el segundo exacto en que ocurrieron.                                                                                                                                                                            |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                        |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                        |
| **Precondición**      | Desviaciones detectadas (CU-28).                                                                                                                                                                                                                                        |
| **Flujo de Suceso**   | **Registrar errores**  <br>1. El Worker agrupa desviaciones contiguas en un solo "microerror".  <br>2. Asigna el timestamp de inicio y fin del error.  <br>3. Identifica la articulación afectada (ej. "brazo derecho").  <br>4. Guarda en la estructura de resultados. |
| **Postcondición**     | Lista de microerrores con marcas de tiempo generada.                                                                                                                                                                                                                    |
| **Excepción**         | **Sin desviaciones**  <br>1. El alumno no superó ningún umbral.  <br>2. La lista de microerrores queda vacía.                                                                                                                                                           |
