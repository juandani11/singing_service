#### CU-43: Visualizar evolución de puntuación y métricas

| Campo                 | Detalle                                                                                                                                                                                                                                                                            |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-43: Visualizar evolución de puntuación y métricas                                                                                                                                                                                                                               |
| **Propósito**         | Motivar al alumno mostrando su mejora a lo largo del tiempo.                                                                                                                                                                                                                       |
| **Descripción**       | La app genera gráficos de líneas con la progresión de los puntajes.                                                                                                                                                                                                                |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                             |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                             |
| **Precondición**      | Haber realizado múltiples intentos de la misma rutina (idealmente).                                                                                                                                                                                                                |
| **Flujo de Suceso**   | **Visualizar evolución**  <br>1. El alumno entra a "Mi Progreso".  <br>2. La app solicita los datos históricos.  <br>3. El sistema calcula la evolución (puntaje global y parciales).  <br>4. La app dibuja un gráfico de líneas y muestra estadísticas (promedio, mejor puntaje). |
| **Postcondición**     | El alumno comprende su tendencia de mejora.                                                                                                                                                                                                                                        |
| **Excepción**         | **Datos insuficientes**  <br>1. Solo hay 1 intento registrado.  <br>2. La app muestra un mensaje indicando que se necesitan más intentos para graficar.                                                                                                                            |
