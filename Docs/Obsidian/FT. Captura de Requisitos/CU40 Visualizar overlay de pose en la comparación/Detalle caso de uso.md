#### CU-40: Visualizar overlay de pose en la comparación

| Campo                 | Detalle                                                                                                                                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-40: Visualizar overlay de pose en la comparación                                                                                                                                                                                                                        |
| **Propósito**         | Facilitar la comprensión de los errores posturales mostrando el esqueleto sobre el video.                                                                                                                                                                                  |
| **Descripción**       | La app dibuja los landmarks del alumno y del maestro sobre la imagen.                                                                                                                                                                                                      |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                     |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                     |
| **Precondición**      | Estar en la reproducción comparativa (CU-39).                                                                                                                                                                                                                              |
| **Flujo de Suceso**   | **Activar overlay**  <br>1. El alumno activa el interruptor "Mostrar Esqueleto".  <br>2. La app lee los landmarks guardados.  <br>3. Dibuja líneas y puntos sobre los cuerpos en el video en tiempo real.  <br>4. Colorea en rojo las articulaciones con mayor desviación. |
| **Postcondición**     | El alumno visualiza claramente sus desviaciones corporales.                                                                                                                                                                                                                |
| **Excepción**         | **Renderizado lento**  <br>1. El dispositivo no soporta el dibujo en tiempo real.  <br>2. La app reduce la tasa de frames del overlay o desactiva la función.                                                                                                              |
