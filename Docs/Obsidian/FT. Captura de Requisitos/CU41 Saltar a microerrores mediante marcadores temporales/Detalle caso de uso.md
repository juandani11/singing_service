#### CU-41: Saltar a microerrores mediante marcadores temporales

| Campo                 | Detalle                                                                                                                                                                                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-41: Saltar a microerrores mediante marcadores temporales                                                                                                                                                                                                                         |
| **Propósito**         | Ahorrar tiempo al alumno permitiéndole ir directamente a las partes que falló.                                                                                                                                                                                                      |
| **Descripción**       | El reproductor muestra marcas en la línea de tiempo y botones para saltar a ellas.                                                                                                                                                                                                  |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                              |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                              |
| **Precondición**      | Estar en la vista de resultados o comparación.                                                                                                                                                                                                                                      |
| **Flujo de Suceso**   | **Saltar a error**  <br>1. El alumno visualiza la línea de tiempo con marcas rojas.  <br>2. Presiona una marca o selecciona un error del listado.  <br>3. La app adelanta o retrocede el video hasta el timestamp exacto.  <br>4. El video comienza a reproducirse desde ese punto. |
| **Postcondición**     | El alumno analiza el error específico.                                                                                                                                                                                                                                              |
| **Excepción**         | **Timestamp fuera de rango**  <br>1. El video es más corto que el timestamp guardado.  <br>2. La app ignora el salto y muestra un error.                                                                                                                                            |
