#### CU-20: Reintentar carga fallida

| Campo                 | Detalle                                                                                                                                                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-20: Reintentar carga fallida sin duplicar intento                                                                                                                                                                                                                      |
| **Propósito**         | Permitir al alumno completar una subida interrumpida sin generar registros basura.                                                                                                                                                                                        |
| **Descripción**       | El sistema retoma la subida fallida asegurando que sea el mismo intento.                                                                                                                                                                                                  |
| **Actores**           | Alumno                                                                                                                                                                                                                                                                    |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                                                    |
| **Precondición**      | Existir una carga fallida o interrumpida.                                                                                                                                                                                                                                 |
| **Flujo de Suceso**   | **Reintentar carga**  <br>1. El alumno presiona "Reintentar" en el intento fallido.  <br>2. El sistema utiliza un ID de intento previo para evitar duplicados.  <br>3. Se reanuda o reinicia la subida del archivo.  <br>4. Al finalizar, se actualiza el mismo registro. |
| **Postcondición**     | El intento se sube correctamente y se mantiene un único registro.                                                                                                                                                                                                         |
| **Excepción**         | **Falla recurrente**  <br>1. La subida vuelve a fallar.  <br>2. El sistema notifica al usuario para intentar más tarde o contactar a soporte.                                                                                                                             |
