#### CU-04: Consultar perfil

| Campo                 | Detalle                                                                                                                                                                                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-04: Consultar perfil                                                                                                                                                                                                                                                             |
| **Propósito**         | Permitir al usuario visualizar su información personal registrada.                                                                                                                                                                                                                  |
| **Descripción**       | El usuario accede a la sección de perfil donde se muestran sus datos.                                                                                                                                                                                                               |
| **Actores**           | Alumno, Instructor                                                                                                                                                                                                                                                                  |
| **Actores Iniciador** | Alumno, Instructor                                                                                                                                                                                                                                                                  |
| **Precondición**      | El usuario debe tener una sesión activa.                                                                                                                                                                                                                                            |
| **Flujo de Suceso**   | **Consultar perfil**  <br>1. El usuario hace clic en la opción "Mi Perfil".  <br>2. La aplicación solicita los datos al servidor.  <br>3. El sistema recupera la información de la base de datos.  <br>4. La aplicación muestra en pantalla nombre, correo, avatar y datos básicos. |
| **Postcondición**     | El usuario visualiza su información personal.                                                                                                                                                                                                                                       |
| **Excepción**         | **Error de conexión**  <br>1. Falla la comunicación con el servidor.  <br>2. La aplicación muestra un mensaje de error y sugiere recargar.                                                                                                                                          |
