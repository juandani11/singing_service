#### CU-45: Revisar detalle de intento (métricas, errores y evidencia visual)

| Campo                 | Detalle                                                                                                                                                                                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-45: Revisar detalle de intento                                                                                                                                                                                                                                                   |
| **Propósito**         | Permitir al instructor auditar y comprender el rendimiento individual de un alumno.                                                                                                                                                                                                 |
| **Descripción**       | El instructor abre el resultado de un intento específico para ver los videos y métricas.                                                                                                                                                                                            |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                          |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                          |
| **Precondición**      | Existir un intento procesado de un alumno vinculado.                                                                                                                                                                                                                                |
| **Flujo de Suceso**   | **Revisar detalle**  <br>1. El instructor selecciona un intento desde el dashboard.  <br>2. La app carga la vista de resultados.  <br>3. Se muestran los puntajes, el video comparativo y los microerrores.  <br>4. El instructor puede reproducir el video y saltar a los errores. |
| **Postcondición**     | El instructor evalúa la ejecución del alumno.                                                                                                                                                                                                                                       |
| **Excepción**         | **Video no disponible**  <br>1. El video fue purgado por políticas de retención.  <br>2. Se muestran solo las métricas numéricas.                                                                                                                                                   |
