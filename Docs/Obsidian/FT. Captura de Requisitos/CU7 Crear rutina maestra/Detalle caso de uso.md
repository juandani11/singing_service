#### CU-07: Crear rutina maestra

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-07: Crear rutina maestra                                                                                                                                                                                                                                                                                                                                   |
| **Propósito**         | Permitir al instructor diseñar una nueva coreografía o rutina base.                                                                                                                                                                                                                                                                                           |
| **Descripción**       | El instructor ingresa los datos de la rutina, instrucciones y parámetros.                                                                                                                                                                                                                                                                                     |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                                                                                                    |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                                                                                                    |
| **Precondición**      | Sesión activa de instructor.                                                                                                                                                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Crear rutina**  <br>1. El instructor accede a "Nueva Rutina".  <br>2. Ingresa nombre, descripción, dificultad y duración.  <br>3. Define los pasos e instrucciones de la rutina.  <br>4. El instructor presiona "Guardar".  <br>5. El sistema valida los datos y guarda la rutina en estado "Borrador/Activa".  <br>6. El sistema muestra la rutina creada. |
| **Postcondición**     | La rutina maestra se guarda en el catálogo del instructor.                                                                                                                                                                                                                                                                                                    |
| **Excepción**         | **Campos obligatorios vacíos**  <br>1. La aplicación detecta campos requeridos sin llenar.  <br>2. Muestra un mensaje de error.  <br>3. El instructor debe completar la información.                                                                                                                                                                          |
