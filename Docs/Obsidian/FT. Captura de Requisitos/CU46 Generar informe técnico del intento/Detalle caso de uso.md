#### CU-46: Generar informe técnico del intento

| Campo                 | Detalle                                                                                                                                                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Caso de Uso**       | CU-46: Generar informe técnico del intento                                                                                                                                                                                                             |
| **Propósito**         | Exportar los resultados del análisis para compartirlos fuera de la plataforma.                                                                                                                                                                         |
| **Descripción**       | El sistema genera un documento (PDF) con los resultados del intento.                                                                                                                                                                                   |
| **Actores**           | Instructor                                                                                                                                                                                                                                             |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                             |
| **Precondición**      | Estar en la vista de detalle de un intento procesado.                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Generar informe**  <br>1. El instructor presiona "Exportar Informe".  <br>2. El sistema extrae las métricas, gráficos y comentarios.  <br>3. Compila un documento PDF estructurado.  <br>4. La app descarga o comparte el archivo en el dispositivo. |
| **Postcondición**     | El instructor obtiene el archivo PDF del intento.                                                                                                                                                                                                      |
| **Excepción**         | **Error de generación**  <br>1. Falla el motor de renderizado de PDF.  <br>2. Se notifica al instructor para intentar más tarde.                                                                                                                       |
