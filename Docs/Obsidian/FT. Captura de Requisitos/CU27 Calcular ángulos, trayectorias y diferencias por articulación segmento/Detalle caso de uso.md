#### CU-27: Calcular ángulos, trayectorias y diferencias por articulación/segmento

| Campo                 | Detalle                                                                                                                                                                                                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-27: Calcular ángulos, trayectorias y diferencias                                                                                                                                                                                                                           |
| **Propósito**         | Obtener métricas cinemáticas para evaluar la técnica del baile.                                                                                                                                                                                                               |
| **Descripción**       | El sistema compara los landmarks alineados del alumno contra los del maestro.                                                                                                                                                                                                 |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                              |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                              |
| **Precondición**      | Alineación temporal completada (CU-26).                                                                                                                                                                                                                                       |
| **Flujo de Suceso**   | **Calcular métricas**  <br>1. El Worker calcula ángulos entre segmentos (ej. codo-hombro).  <br>2. Calcula vectores de trayectoria de movimiento.  <br>3. Resta las coordenadas y ángulos del maestro vs. el alumno.  <br>4. Genera una matriz de diferencias por cada frame. |
| **Postcondición**     | Matriz de diferencias espaciales calculada.                                                                                                                                                                                                                                   |
| **Excepción**         | **Error de cálculo**  <br>1. Datos NaN en los landmarks.  <br>2. Se registra en logs y se salta el frame.                                                                                                                                                                     |
