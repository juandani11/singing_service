#### CU-02: Iniciar sesión

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-02: Iniciar sesión                                                                                                                                                                                                                                                                                                                                                                                 |
| **Propósito**         | Validar la identidad del usuario para permitir el acceso seguro a la plataforma.                                                                                                                                                                                                                                                                                                                      |
| **Descripción**       | El usuario proporciona sus credenciales para obtener una sesión activa.                                                                                                                                                                                                                                                                                                                               |
| **Actores**           | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                                                    |
| **Actores Iniciador** | Alumno, Instructor                                                                                                                                                                                                                                                                                                                                                                                    |
| **Precondición**      | El usuario debe estar registrado previamente.                                                                                                                                                                                                                                                                                                                                                         |
| **Flujo de Suceso**   | **Iniciar Sesión**  <br>1. El usuario accede a la pantalla de inicio de sesión.  <br>2. La aplicación muestra el formulario.  <br>3. El usuario ingresa correo electrónico y contraseña.  <br>4. La aplicación verifica las credenciales en la base de datos.  <br>5. La aplicación genera un token de sesión seguro (JWT).  <br>6. La aplicación redirige al usuario al panel principal (Dashboard). |
| **Postcondición**     | El usuario obtiene un token válido y accede a su cuenta.                                                                                                                                                                                                                                                                                                                                              |
| **Excepción**         | **Credenciales inválidas**  <br>1. La aplicación detecta incoherencia entre correo y contraseña.  <br>2. Se muestra el mensaje "Usuario o contraseña incorrectos".  <br>3. El usuario intenta nuevamente.                                                                                                                                                                                             |
