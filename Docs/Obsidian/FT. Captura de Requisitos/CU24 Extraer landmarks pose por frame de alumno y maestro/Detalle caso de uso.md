#### CU-24: Extraer landmarks/pose por frame de alumno y maestro

| Campo                 | Detalle                                                                                                                                                                                                                                                                           |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-24: Extraer landmarks/pose por frame de alumno y maestro                                                                                                                                                                                                                       |
| **Propósito**         | Obtener la estructura esquelética del cuerpo en cada cuadro del video.                                                                                                                                                                                                            |
| **Descripción**       | El sistema procesa los videos de alumno y maestro para extraer puntos clave (articulaciones).                                                                                                                                                                                     |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                  |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                  |
| **Precondición**      | Los videos deben estar cargados y disponibles en el almacenamiento.                                                                                                                                                                                                               |
| **Flujo de Suceso**   | **Extraer landmarks**  <br>1. El Worker toma los videos de la cola.  <br>2. Ejecuta el modelo de estimación de pose (ej. MediaPipe, OpenPose).  <br>3. Extrae las coordenadas (x, y, z) de las articulaciones por frame.  <br>4. Almacena la matriz de coordenadas temporalmente. |
| **Postcondición**     | Estructura de landmarks extraída para ambos videos.                                                                                                                                                                                                                               |
| **Excepción**         | **Sujeto no detectado**  <br>1. El modelo no detecta una persona en varios frames.  <br>2. El Worker registra una advertencia y omite los frames vacíos.  <br>3. Si falla en la mayoría, marca el intento como "Fallido".                                                         |
