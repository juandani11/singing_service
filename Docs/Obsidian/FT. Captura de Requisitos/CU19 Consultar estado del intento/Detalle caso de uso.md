#### CU-19: Consultar estado del intento

| Campo                 | Detalle                                                                                                                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Caso de Uso**       | CU-19: Consultar estado del intento                                                                                                                                                                                                  |
| **Propósito**         | Mantener informado al alumno sobre el progreso del análisis de su video.                                                                                                                                                             |
| **Descripción**       | El alumno visualiza en qué etapa se encuentra su intento (pendiente, procesando, completado).                                                                                                                                        |
| **Actores**           | Alumno                                                                                                                                                                                                                               |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                               |
| **Precondición**      | Haber subido un intento.                                                                                                                                                                                                             |
| **Flujo de Suceso**   | **Consultar estado**  <br>1. El alumno accede al historial o detalle del intento.  <br>2. El sistema consulta el estado actual en la base de datos.  <br>3. La app muestra el estado con un indicador visual (spinner, check, etc.). |
| **Postcondición**     | El alumno conoce el estado del procesamiento.                                                                                                                                                                                        |
| **Excepción**         | **Ninguna** (el sistema siempre debe retornar un estado válido o desconocido).                                                                                                                                                       |
