#### CU-10: Editar rutina maestra

| Campo                 | Detalle                                                                                                                                                                                                                                                                 |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-10: Editar rutina maestra                                                                                                                                                                                                                                            |
| **Propósito**         | Modificar los datos o instrucciones de una rutina existente.                                                                                                                                                                                                            |
| **Descripción**       | El instructor actualiza los campos de la rutina y guarda los cambios.                                                                                                                                                                                                   |
| **Actores**           | Instructor                                                                                                                                                                                                                                                              |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                              |
| **Precondición**      | Ser el dueño de la rutina y tener sesión activa.                                                                                                                                                                                                                        |
| **Flujo de Suceso**   | **Editar rutina**  <br>1. El instructor entra al detalle de la rutina.  <br>2. Selecciona "Editar".  <br>3. Modifica los campos necesarios.  <br>4. Presiona "Guardar".  <br>5. El sistema valida y actualiza la base de datos.  <br>6. Se muestra un mensaje de éxito. |
| **Postcondición**     | La rutina es actualizada correctamente.                                                                                                                                                                                                                                 |
| **Excepción**         | **Error de concurrencia**  <br>1. Otro proceso modificó la rutina.  <br>2. El sistema advierte sobre los cambios.  <br>3. El instructor decide sobrescribir o recargar.                                                                                                 |
