#### CU-35: Generar feedback vocal con segmentos desafinados y recomendaciones

| Campo                 | Detalle                                                                                                                                                                                                                                                                |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-35: Generar feedback vocal                                                                                                                                                                                                                                          |
| **Propósito**         | Brindar al alumno información útil sobre cómo mejorar su canto.                                                                                                                                                                                                        |
| **Descripción**       | El sistema traduce los errores de afinación en textos explicativos y consejos.                                                                                                                                                                                         |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                       |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                       |
| **Precondición**      | Evaluación de afinación (CU-34).                                                                                                                                                                                                                                       |
| **Flujo de Suceso**   | **Generar feedback**  <br>1. El Worker identifica los segmentos con peor puntaje.  <br>2. Genera marcas de tiempo para esos segmentos.  <br>3. Redacta recomendaciones basadas en reglas (ej. "Sube el tono en el segundo 15").  <br>4. Asocia el feedback al intento. |
| **Postcondición**     | Mensajes de retroalimentación vocal listos para mostrarse.                                                                                                                                                                                                             |
| **Excepción**         | **Sin errores graves**  <br>1. El puntaje es muy alto.  <br>2. Se genera un mensaje de felicitación.                                                                                                                                                                   |
