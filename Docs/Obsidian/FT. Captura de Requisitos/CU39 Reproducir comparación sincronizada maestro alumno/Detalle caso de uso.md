#### CU-39: Reproducir comparación sincronizada maestro/alumno

| Campo                 | Detalle                                                                                                                                                                                                                                       |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-39: Reproducir comparación sincronizada maestro/alumno                                                                                                                                                                                     |
| **Propósito**         | Permitir al alumno ver sus movimientos al lado de los del instructor.                                                                                                                                                                         |
| **Descripción**       | La app muestra un reproductor de video doble (o superpuesto) con sincronización exacta.                                                                                                                                                       |
| **Actores**           | Alumno                                                                                                                                                                                                                                        |
| **Actores Iniciador** | Alumno                                                                                                                                                                                                                                        |
| **Precondición**      | Video maestro disponible y video del intento procesado.                                                                                                                                                                                       |
| **Flujo de Suceso**   | **Reproducir comparación**  <br>1. El alumno presiona "Comparar".  <br>2. La app carga ambos videos.  <br>3. El reproductor ajusta los tiempos para sincronizar inicio y beats.  <br>4. Se reproducen simultáneamente (lado a lado o espejo). |
| **Postcondición**     | El alumno observa la diferencia de ejecución.                                                                                                                                                                                                 |
| **Excepción**         | **Video no cargado**  <br>1. El video original fue eliminado.  <br>2. La app advierte que no se puede realizar la comparación visual.                                                                                                         |
