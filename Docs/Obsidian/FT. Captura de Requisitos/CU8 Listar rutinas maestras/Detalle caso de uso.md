#### CU-08: Listar rutinas maestras

| Campo                 | Detalle                                                                                                                                                                                                                                 |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-08: Listar rutinas maestras                                                                                                                                                                                                          |
| **Propósito**         | Permitir al instructor visualizar todas sus rutinas creadas.                                                                                                                                                                            |
| **Descripción**       | El sistema muestra un listado paginado de las rutinas asociadas al instructor.                                                                                                                                                          |
| **Actores**           | Instructor                                                                                                                                                                                                                              |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                              |
| **Precondición**      | Sesión activa de instructor.                                                                                                                                                                                                            |
| **Flujo de Suceso**   | **Listar rutinas**  <br>1. El instructor accede al módulo de "Rutinas".  <br>2. El sistema solicita el listado.  <br>3. El sistema recupera las rutinas del instructor.  <br>4. Se muestran en pantalla con nombre, dificultad y fecha. |
| **Postcondición**     | El instructor visualiza sus rutinas.                                                                                                                                                                                                    |
| **Excepción**         | **Sin rutinas registradas**  <br>1. El sistema detecta que no hay rutinas.  <br>2. Muestra un mensaje de "No hay rutinas disponibles".  <br>3. Ofrece un botón para crear una nueva.                                                    |
