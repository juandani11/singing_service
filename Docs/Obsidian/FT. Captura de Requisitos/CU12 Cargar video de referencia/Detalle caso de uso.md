#### CU-12: Cargar y validar video de referencia

| Campo                 | Detalle                                                                                                                                                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-12: Cargar y validar video de referencia                                                                                                                                                                                                                                           |
| **Propósito**         | Proveer un video maestro para que el alumno lo use como guía.                                                                                                                                                                                                                         |
| **Descripción**       | El instructor sube un video y el sistema valida formato y duración.                                                                                                                                                                                                                   |
| **Actores**           | Instructor                                                                                                                                                                                                                                                                            |
| **Actores Iniciador** | Instructor                                                                                                                                                                                                                                                                            |
| **Precondición**      | Estar en la creación o edición de una rutina.                                                                                                                                                                                                                                         |
| **Flujo de Suceso**   | **Cargar video**  <br>1. El instructor selecciona "Subir Video".  <br>2. Elige el archivo desde su dispositivo.  <br>3. El sistema valida formato (mp4) y tamaño máximo.  <br>4. El sistema sube el video al almacenamiento.  <br>5. El sistema guarda la URL del video en la rutina. |
| **Postcondición**     | El video queda vinculado a la rutina.                                                                                                                                                                                                                                                 |
| **Excepción**         | **Formato inválido**  <br>1. El video no es mp4 o excede el tamaño.  <br>2. El sistema rechaza la subida.  <br>3. Muestra un mensaje con los requisitos.                                                                                                                              |
