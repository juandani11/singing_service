#### CU-32: Persistir métricas, errores, mensajes y trazabilidad

| Campo                 | Detalle                                                                                                                                                                                                                                                                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-32: Persistir métricas, errores, mensajes y trazabilidad                                                                                                                                                                                                                                                                               |
| **Propósito**         | Guardar de forma segura todos los resultados del análisis en la base de datos.                                                                                                                                                                                                                                                            |
| **Descripción**       | El Worker guarda en la base de datos los puntajes, microerrores y datos de auditoría.                                                                                                                                                                                                                                                     |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                                                                          |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                                                                          |
| **Precondición**      | Análisis biomecánico y de audio completados.                                                                                                                                                                                                                                                                                              |
| **Flujo de Suceso**   | **Persistir datos**  <br>1. El Worker consolida los puntajes (global, parciales) y microerrores.  <br>2. Abre una transacción en la base de datos.  <br>3. Inserta los registros asociándolos al ID del intento.  <br>4. Agrega marcas de tiempo de inicio y fin del procesamiento (trazabilidad).  <br>5. Hace commit de la transacción. |
| **Postcondición**     | Resultados disponibles para la app móvil.                                                                                                                                                                                                                                                                                                 |
| **Excepción**         | **Fallo de conexión a DB**  <br>1. Se interrumpe la comunicación con la base de datos.  <br>2. El Worker revierte la transacción y reintenta con backoff exponencial.                                                                                                                                                                     |
