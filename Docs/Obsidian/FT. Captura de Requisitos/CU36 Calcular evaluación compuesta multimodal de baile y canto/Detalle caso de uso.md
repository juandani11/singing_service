#### CU-36: Calcular evaluación compuesta multimodal de baile y canto

| Campo                 | Detalle                                                                                                                                                                                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-36: Calcular evaluación compuesta multimodal                                                                                                                                                                                                                  |
| **Propósito**         | Unificar el desempeño de baile y canto en una sola métrica final.                                                                                                                                                                                                |
| **Descripción**       | El sistema pondera el puntaje biomecánico y el vocal para generar una evaluación integral.                                                                                                                                                                       |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                 |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                 |
| **Precondición**      | Puntaje biomecánico (CU-31) y vocal (CU-34) calculados.                                                                                                                                                                                                          |
| **Flujo de Suceso**   | **Evaluación multimodal**  <br>1. El Worker recupera ambos puntajes parciales.  <br>2. Aplica los porcentajes definidos (ej. 50% baile, 50% canto).  <br>3. Suma los resultados para obtener la nota final compuesta.  <br>4. Almacena el resultado consolidado. |
| **Postcondición**     | Nota final del intento generada.                                                                                                                                                                                                                                 |
| **Excepción**         | **Falta una modalidad**  <br>1. Solo se evaluó baile (audio falló).  <br>2. El sistema asigna el 100% del peso a la modalidad disponible.                                                                                                                        |
