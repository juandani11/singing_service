#### CU-31: Calcular puntaje global ponderado de 0 a 100

| Campo                 | Detalle                                                                                                                                                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Caso de Uso**       | CU-31: Calcular puntaje global ponderado de 0 a 100                                                                                                                                                                                                                                   |
| **Propósito**         | Obtener una calificación final del desempeño del baile.                                                                                                                                                                                                                               |
| **Descripción**       | El sistema combina los puntajes parciales con diferentes pesos específicos.                                                                                                                                                                                                           |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                                      |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                                      |
| **Precondición**      | Puntajes parciales calculados (CU-30).                                                                                                                                                                                                                                                |
| **Flujo de Suceso**   | **Calcular puntaje global**  <br>1. El Worker aplica los pesos configurados (ej. brazos 20%, piernas 40%).  <br>2. Multiplica cada puntaje parcial por su peso.  <br>3. Suma los resultados para obtener un puntaje de 0 a 100.  <br>4. Guarda el resultado en el objeto del intento. |
| **Postcondición**     | Puntaje final calculado.                                                                                                                                                                                                                                                              |
| **Excepción**         | **Pesos suman más de 100%**  <br>1. Error de configuración.  <br>2. El Worker normaliza los pesos automáticamente y alerta al sistema.                                                                                                                                                |
