#### CU-37: Generar feedback técnico con recomendaciones concretas

| Campo                 | Detalle                                                                                                                                                                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Caso de Uso**       | CU-37: Generar feedback técnico con recomendaciones concretas                                                                                                                                                                                                            |
| **Propósito**         | Ofrecer una guía de mejora al alumno basada en los resultados de la IA.                                                                                                                                                                                                  |
| **Descripción**       | El sistema consolida los microerrores de baile y canto en un informe de texto comprensible.                                                                                                                                                                              |
| **Actores**           | Sistema / Worker                                                                                                                                                                                                                                                         |
| **Actores Iniciador** | Sistema / Worker                                                                                                                                                                                                                                                         |
| **Precondición**      | Métricas y errores persistidos (CU-32) y evaluación multimodal (CU-36).                                                                                                                                                                                                  |
| **Flujo de Suceso**   | **Generar feedback**  <br>1. El Worker analiza los segmentos con peor puntuación.  <br>2. Genera mensajes técnicos (ej. "Mantén la espalda recta").  <br>3. Vincula los mensajes a los timestamps de los microerrores.  <br>4. Almacena el feedback en la base de datos. |
| **Postcondición**     | Feedback completo listo para la app móvil.                                                                                                                                                                                                                               |
| **Excepción**         | **Intento perfecto**  <br>1. No se detectaron microerrores.  <br>2. Se genera un feedback de refuerzo positivo.                                                                                                                                                          |
